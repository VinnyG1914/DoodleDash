# DoodleDash

A free drawing and guessing game, like skribbl.io, for phones and laptops. One player draws a word, everyone else types guesses. Nobody needs to share their screen: the drawing appears live on every player's own device.

There's nothing to install and no server to run. Whoever creates the game becomes the host, and their browser runs it. Every message goes through the free PeerJS server over a normal secure web connection (port 443), so it works on company networks and VPNs that block direct device-to-device links (see `js/link.js`).

## Putting it online / updating it (GitHub Pages)

1. Upload **everything inside the `DoodleDash` folder** to your GitHub repository, so `index.html` sits at the top of the repository (or the folder you publish).
2. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
3. After a minute or two the game is at `https://YOUR-NAME.github.io/REPO-NAME/`.

After any change, upload the changed files again. Uploading a file with the same name replaces the old one. Ask players to press **Ctrl + F5** (or close and reopen the tab on a phone) so they get the new version.

## Playing

**Create a game (host):**
1. Open the site and tap **🎨 Create game**. Pick a nickname and a character.
2. Tap **📨 Invite** to send the link (on a phone it opens the share menu, on a laptop it copies the link). The link has the PIN filled in. You can also just tell people the 6-digit **Game PIN**.
3. Choose the settings: rounds (2 by default), drawing time, letter hints and which word packs to use.
4. When everyone is in, turn on **Lock room** if you like (you can also change it during the game), then tap **▶ Start game**.

**Join a game:** open the site, tap **🔑 Join game**, type the PIN, then pick a nickname and a character. Or just open the invite link.

**A turn:** the artist picks one of three words and has the drawing time to draw it. Everyone else types guesses in the chat. A guess that is one or two letters off shows "close!". Letter hints appear as time runs out. Each player draws once per round.

## Keeping strangers out

- There is no public list of games. You can only join with the PIN.
- **Lock room** stops anyone new from joining. Players who are already in can still rejoin if they drop.
- In the lobby, the host can tap a player to remove them. They can't come back into that game.
- A game holds up to 12 players.

## Hosting from a phone

It works, but keep the DoodleDash page open on screen for the whole game. If the host locks the phone or switches apps, the browser pauses the page and the game stops for everyone. The game asks the phone to stay awake, and shows a reminder in the lobby. A laptop is the safest host.

If the host's page closes, open the site again on the same device and tap **Resume** on the home screen. The same PIN comes back and players reconnect on their own.

## Scoring

- **Guessers:** from 500 points for an instant guess down to 50 for a last-second guess.
- **Artist:** 100 points plus up to 300 more, depending on how many players guessed. The artist gets nothing if nobody guessed.
- After the last round, a podium shows the top three.

## If something goes wrong

- **"Connection to the game failed":** check the PIN is right and the host's page is still open. The player may also have an old version. Press Ctrl + F5 (or reopen the tab) and join again.
- **The host stays on "Getting your game online…":** the free PeerJS server is busy or limiting your connection. Wait a few minutes and reload. It limits a device that opens many games in a short time.
- **A player refreshes or drops:** they rejoin with the same device and keep their score. The drawing so far appears again.

## Avatars

Players pick from the same cartoon characters as Team Quiz. To add your own pictures, copy them into `avatars\custom\`, double-click **`Update avatars.bat`**, then upload again. Anyone with the link can see the pictures.

## Files

| Path | What it is |
|---|---|
| `index.html`, `css/style.css` | The one page everyone uses (host and players) |
| `js/app.js` | Screens, chat, drawing tools |
| `js/host.js` | The game itself: turns, words, timers, scores (runs on the host's device) |
| `js/board.js` | The drawing board and how drawings are sent |
| `js/words.js` | Word packs. Edit this file to add or remove words |
| `js/link.js` | Sends game messages through the PeerJS server instead of direct links |
| `js/common.js` | Avatars, backgrounds, sounds, animations |
| `js/config.js` | Connection settings and limits |
| `js/avatars.js` | Avatar list, generated by `Update avatars.bat` |
| `assets/bg/`, `avatars/`, `fonts/` | Pictures and font |
| `CREDITS.md` | Where the photos, characters and font come from |
| `_dev/`, `tools/` | Tests and helper scripts (not needed online, harmless if uploaded) |
